# 📝 Todo List Application

A responsive Todo List application built using Vanilla JavaScript, HTML, and CSS.

This project was created to practice core frontend development concepts including DOM Manipulation, Event Delegation, Local Storage, Dynamic UI Updates, and CRUD Operations.

## ✨ Features

### Task Management

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Clear all completed tasks

### Filtering

- View All Tasks
- View Active Tasks
- View Completed Tasks

### Statistics

- Total Tasks Counter
- Completed Tasks Counter
- Remaining Tasks Counter

### Persistence

- Save tasks using Local Storage
- Restore tasks after page refresh

### User Experience

- Add tasks using Enter key
- Dynamic task rendering
- Responsive UI
- Completed task styling
